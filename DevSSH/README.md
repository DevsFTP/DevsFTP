# DevSSH — Standalone SSH Terminal

DevSSH is a high-performance, standalone SSH terminal application designed for speed, security, and developer efficiency.

## Features
- Hardware-accelerated terminal rendering via `@xterm/xterm`
- AES-256 encrypted credential store
- Multi-session tabbed SSH console management
- Built-in SSH tunnel & port forwarding controls

## Quick Start
```bash
cd DevSSH
npm install
npm run dev
```
