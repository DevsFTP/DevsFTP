## 🌟 What's New in v1.0.1

### 1. 🔖 Comprehensive Bookmarking System Refactor

#### Local System Bookmarks Drawer (`#local-bookmarks-drawer`)
- **Scoped Navigation**: Nested directly inside the Local System pane (`top: 36px`, `width: 100%`, `height: calc(100% - 36px)`), leaving the pane header bar 100% visible while sliding out.
- **Quick Actions**: Add current local directory with 1 click (`+ Add Current Folder`), jump directly to any saved folder (`➡️`), or remove shortcuts (`🗑️`).

#### Scoped Profile Bookmarks Drawer (`#profile-bookmarks-drawer`)
- **Server Scoped**: Dynamically titles `🔖 Bookmarks - [Profile Name]` for the active remote connection.
- **Clean Uncluttered UI**: Lists saved remote folder shortcuts with borderless `➡️` Go and `🗑️` Delete icon buttons, keeping the drawer clean and scoped without repeating redundant profile tags.

#### Master Global Bookmarks Manager Modal (`#global-bookmarks-modal`)
- **1:1 Alignment with Pending Edits Manager**: Matches the Pending Remote Edits Manager in width (`920px`), height (`600px`), filter toolbar controls, table grid alignment (`30%` / `22%` / `28%` / `20%`), and footer action bar.
- **Unified Aggregation**: Aggregates all saved bookmarks (Local System, Global Storage, and Server Profiles) into one master table.
- **Filter Toolbar**:
  - `Filter by Type`: `All Bookmark Types`, `💻 Local System`, `🌐 Remote Servers`
  - `Filter by Profile`: Dynamic list of server profiles with `● Profile Name` colored bullet dots matching Pending Edits (`app.js` L1740-1744).
  - Live search input: `🔍 Search bookmarks...`
  - Summary counter: `Bookmarks: <strong style="color: #F59E0B;">X</strong>`
- **Table Grid & Multi-Select Management**:
  - Header `☑` Select / Deselect All checkbox.
  - `Profile` cell displays:
    - **Local System**: `💻 Local System` (uses `💻` icon with no assigned color dot).
    - **Remote Server**: `● ${profileName}` (uses 8px colored dot matching that profile's accent color `#68a063`, `#F59E0B`, etc.).
  - Actions column: Borderless `➡️` Go icon button and `🗑️` delete icon button.
- **Footer Action Bar**:
  - `🗑️ Discard Checked` button for bulk bookmark deletion.
  - `+ Add Local Folder` & `+ Add Remote Folder` buttons.
  - `✕ Close` button.

#### Tools Menu & Settings Backup Consolidation
- **📦 Export Workspace Package...** (`Tools` ➔ `📦 Export Workspace Package` or `Settings` ➔ `Security`): Consolidates all server profiles, 3-layer bookmarks, workspace preferences, and scheduled sync jobs into a single `.devsftp-bundle.json` file.
- **📥 Import Workspace Package...** (`Tools` ➔ `📥 Import Workspace Package` or `Settings` ➔ `Security`): 1-click restore for complete workstation setup. Replaces scattered export/import entries for a clean, non-bloated menu experience.

### 2. 🖱️ Context Menu & File Tree Gold Stars
- **Context Menu Submenu**: Added `🔖 Bookmark` ➔ `⭐ Add to Bookmarks` / `🗑️ Remove from Bookmarks` in the right-click context menu directly below `🔀 Sort By`.
- **Gold Star Badges**: Renders a gold star (`⭐`) next to any folder or file in the file list tables that is saved in your bookmarks.

---

### 3. 🎨 UI & Design Consistency Updates
- **Borderless Emoji Action Buttons**: Converted action buttons into clean emoji icon buttons (`➡️` Go & `🗑️` Delete) with zero border and hover scale effects.
- **Exact CSS Alignment**: Aligned all modal cards, table rows, filter dropdowns, and button paddings with `PendingEditsManager` for a consistent experience across all modals in DevsFTP.
